# Aphyn examples

Examples and demo projects for the [Aphyn](https://github.com/are-you-fruits-studio/aphyn) game engine.
Each example is a standalone Aphyn project under `examples/<name>/` that you can run with `cargo` or package
with `aphyn build`.

**Work in progress:** the examples are being moved here from the engine repository one by one.

## Examples

| Example | What it shows | Run |
|---|---|---|
| [cubes](examples/cubes) | Spinning, sliding cubes: a mesh built in code, unlit material, camera, transform hierarchy | `just dev cubes` |
| [ecs](examples/ecs) | The ECS without rendering: spawning, queries, optional components and resources, despawning (console output) | `just dev ecs` |
| [boids](examples/boids) | A hundred triangles flocking: a simulation split into ordered systems, settings in a resource | `just dev boids` |
| [gizmos](examples/gizmos) | Debug lines in clip, window and world space, with a fly camera (WASD, R/F, Q/E) | `just dev gizmos` |
| [collisions](examples/collisions) | Collider grid picked with the mouse, and an overlap test between a box and a rotated box | `just dev collisions` |
| [text](examples/text) | Bitmap-font text in world space, rewritten every frame with the elapsed time | `just dev text` |
| [ui](examples/ui) | Rect-based UI: nested and masked panels, a laid-out column, a label, a square following the mouse | `just dev ui` |
| [material](examples/material) | Custom WGSL shaders: a material template, a material recolored at runtime, a vignette post-processing pass | `just dev material` |
| [physics](examples/physics) | Rigidbodies drawn as collider wireframes: layers, a mesh floor, a compound body, mouse dragging, an orbit camera | `just dev physics` |
| [audio_screen_saver](examples/audio_screen_saver) | A looping music clip (generated by a script) and its live waveform drawn with gizmos | `just dev audio_screen_saver` |
| [normals](examples/normals) | Normal mapping: a tiled normal map lit by a point light that follows the mouse | `just dev normals` |
| [bloom](examples/bloom) | Bloom post-processing: a strong point light blows a floor out past white and it glows; the cube mesh is loaded from `.obj` | `just dev bloom` |
| [showcase](examples/showcase) | The engine's showcase loop: 450 boids in three flocks, lit and emissive materials, bloom, ACES, a normal-mapped floor, gizmos, text; `--capture` writes the loop as PNG frames | `just dev showcase` |
| [audio_sfx](examples/audio_sfx) | Sound effects on number keys: one-shots, a loop, mixing, a stereo clip (left, right, both), mono 44.1 kHz clips, live left and right waveforms | `just dev audio_sfx` |
| [mouse_input](examples/mouse_input) | Mouse position, buttons and wheel drawn with gizmos: a circle following the cursor that the wheel resizes, click and drag-marquee selection, right-click pings | `just dev mouse_input` |
| [http_control](examples/http_control) | The window color set over a loopback HTTP port: a server thread hands commands to the ECS | `just dev http_control` |
| [babble](examples/babble) | Typed text turned into procedural gibberish speech, played back while a circle pulses with its loudness; sliders for speed, pitch, vibrato and brightness | `just dev babble` |

`just dev <name>` is `cargo run --manifest-path examples/<name>/scripts/Cargo.toml`.
